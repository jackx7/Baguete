# Órbita landing page

Responsive, Portuguese-language concept for an independent design studio. Brand and copy are provisional; replace `contato@example.com` with the real contact address before commercial use.

## Development

The site uses plain HTML and CSS. No install or build step is required. Run `node server.mjs` and open `http://127.0.0.1:3000`.

## Structure

- `dist/index.html`: page structure and copy.
- `dist/styles.css`: responsive styling.

Google Fonts supplies DM Sans and Manrope; system fonts are used when unavailable. There is no form backend, JavaScript, or automated test runner. Check anchor navigation, contact destination, keyboard focus, and mobile/desktop layouts after changes.
